Local Run Command
-----------------

    cd ~/testedcloud/cloudrun/testedcloud-chat-events-api
    source .venv/bin/activate

    export PUBSUB_ENABLED=true
    export GCP_PROJECT_ID=majestic-layout-255620
    export PUBSUB_TOPIC_ID=testedcloud-chat-events

    uvicorn app:app --reload --port 8088

Pub/Sub Publish Test

    curl -i -X POST http://localhost:8088/events \
