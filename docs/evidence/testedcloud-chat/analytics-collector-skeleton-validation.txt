Privacy Behavior
----------------

The collector rejects metadata keys that may contain sensitive content.

Blocked metadata examples:

    message_text
    text
    body
    email
    recipient_email
    participant_email
    participant_emails
    display_name
    participant_display_name
    participant_display_names
    token
    auth_token
    id_token
    password

This protects the analytics pipeline from accidentally receiving message content, participant emails, tokens, or other sensitive values.

Validation Logic
----------------

The collector currently validates:

    event_type is supported
    source is testedcloud-chat-android
    user_id is present
    created_at is present
    conversation_id is present for supported conversation/message events
    message_sent includes metadata.message_length
    conversation_deleted_for_user includes delete_scope = for_me
    conversation_deleted_for_user includes delete_model = deletedAtByUser
    sensitive metadata keys are rejected
